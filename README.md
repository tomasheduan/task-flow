# TaskFlow - Proyecto inicial

Proyecto simple para practicar Git y GitHub en 12 etapas progresivas.

## Cómo ejecutar
Abrir `index.html` en el navegador.

## Antes de empezar
Desde esta carpeta:

```bash
git init
git add .
git commit -m "Crear proyecto inicial TaskFlow"
```

Después seguir los archivos de `01_ETAPAS` en orden.
